## Descripción
Sitio web de e-commerce que simula la experiencia de compra de una mueblería, 
construido íntegramente con tecnologías del lado del cliente (sin backend). 
Los productos se gestionan localmente mediante JavaScript.

### Funcionalidades
- Página de inicio con productos destacados cargados dinámicamente
- Catálogo de productos con buscador funcional
- Vista de detalle de cada producto
- Formulario de contacto con validación del lado del cliente

## Tecnologías utilizadas
- **HTML5** semántico
- **CSS3** — diseño responsivo mobile-first con Flexbox
- **JavaScript** — manipulación del DOM, manejo de eventos, carga asíncrona 
  de datos, gestión de productos mediante arrays de objetos

## Cómo ejecutar el proyecto
1. Cloná el repositorio
2. Abrí `index.html` con Live Server (o cualquier servidor local)
